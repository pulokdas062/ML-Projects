# Student Performance Machine Learning Project
## Problem Idea

This project explores student academic performance using basic data analysis and
machine learning concepts. We will investigate factors such as study hours,
sleep hours, attendance, and other student-related information to understand
their relationship with academic outcomes.

The initial stage of the project focuses on data manipulation, exploration,
and understanding basic machine learning concepts before developing a complete
machine learning model.

## Current Dataset Status

The current notebook uses a small manually created dataset containing 6 student
samples and 6 columns.

The dataset contains the following information:

- Student name
- Study hours
- Sleep hours
- Attendance
- Snack purchases
- Pass/Fail status

The current dataset is only being used for preliminary exploration and learning.
A larger dataset may be added in future stages of the project.

## Notebook

The first notebook is:

`notebooks/lab01_setup.ipynb`

It contains basic Python, NumPy, and Pandas exercises related to the project.
The notebook includes basic calculations, data filtering, sorting, and an
introduction to reproducibility using random seeds.
